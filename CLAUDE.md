# Claude Instructions

This repo uses a shared agentic development protocol.

For local-only target repository installs, read `.agent-protocol/AGENTS.md` first. For this protocol-template source repository, read `AGENTS.md` first.

Before making changes, read:

1. the root `AGENTS.md` bootstrap when present
2. `<protocol-root>/AGENTS.md`
3. `<protocol-root>/docs/agentic-workflow.md`
4. `<protocol-root>/multiagent/protocol.md`
5. relevant files under `<protocol-root>/multiagent/policies/`
6. the active GitHub Issue, or an allowed local task file under `<protocol-root>/multiagent/tasks/`

Follow `<protocol-root>/AGENTS.md` as the source of truth.
